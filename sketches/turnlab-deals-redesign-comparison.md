# TurnLab deals page wireframe + copy comparison

## Recommendation
Ship the **Featured deals first** direction.

Why:
- Better for cold SEO traffic landing directly on `/deals`
- Establishes trust before asking for affiliate clicks
- Matches TurnLab's more editorial, guidance-first brand voice
- Gives us a clean analytics structure: hero CTA, featured deals, retailers, categories, alerts

## Proposed hero copy

**Eyebrow**
Best ski deals today

**Headline**
Find the ski deals worth clicking before the good sizes disappear.

**Body**
TurnLab surfaces the best ski deals from community finds, retailer sale pages, and affiliate-friendly gear categories so you can spot real savings faster — without digging through junk threads or generic storefront search results.

**Primary CTA**
See today’s top deals

**Secondary CTA**
Browse by category

**Trust strip**
- Updated today at 7:15 AM
- 18 fresh deals this week
- Sources linked to originals
- Affiliate links clearly labeled

## Recommended page structure
1. Hero with trust strip and 2 CTAs
2. Top deals today
3. Shop by retailer
4. Shop by category
5. Deal-hunting tips / trust notes
6. Deal alerts signup

## Copy principles for implementation
- Use proof-oriented wording before monetization-oriented wording
- Replace vague labels like "Shop on Amazon" with intent labels like "See jacket deals"
- Avoid promising "daily" freshness unless the data pipeline can support it
- Keep affiliate disclosure explicit, but do not lead with it above the best-value content
